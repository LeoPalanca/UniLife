01 Color

A teal pull, a coral push, on warm paper.

Primary is gravity-teal — the attracting mass. Coral is its semantic opposite: deterrence, negative sentiment, fallback. Everything sits on a warm off-white so the page reads as printed matter, not a screen UI.

03 Brand mark

Four ways to set ErasmusGravity.

System fonts only, so distinction is typographic. Each treatment keeps "Erasmus" quieter and lets "Gravity" carry the mass. Pick one for the sticky topbar.

A · Weight split ErasmusGravity Regular + bold, single teal accent. The recommended default — quiet, legible, scalable.
B · Color split ErasmusGravity Teal pull, coral push — the two semantic forces, stated in the wordmark itself.
C · Tracked + rule ErasmusGravity Uppercase, tracked, with a thin teal rule fading right — editorial masthead energy.
D · Orbital accent ★ ErasmusGravity Weight split plus a tiny orbital glyph — a body on an elliptical path. Used across the dashboard.

06 Micro-interactions

Restrained, legible feedback.

Motion clarifies, never decorates. Each interaction is documented below.

Table sort

Click a header to toggle ascending/descending. Active header goes bold; its arrow fills (▲/▼).

Tooltip

Appears on hover, 12px right & below the cursor. Max-width 260px. Dark overlay, white text.

Bar hover

Subtle brightness increase on the hovered bar — no layout shift.

Scatter point hover

Radius grows +2px and the white stroke thickens to lift the point forward.

Map cluster click

Zooms in and expands the cluster into its constituent markers.

View mode

Free view ⇄ Explore: the topbar's full control surface folds away in Free view and unfolds in Explore.
