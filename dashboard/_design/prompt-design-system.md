# Prompt: ErasmusGravity Design System

Build a **design system reference page** (`design-system.html`) for a research
dashboard called **ErasmusGravity**.

## Context

ErasmusGravity is a data-journalism dashboard that visualises Erasmus+ student
mobility flows across Europe through a gravity-model lens (the Newtonian
analogy: bilateral student flows are "attracted" by salary gaps, quality of
life, and institution quality between origin and destination countries).

The dashboard is a **single self-contained HTML file** generated by Python —
no build tools, no npm, no framework. It is deployed as a static page at
`unilife.ellep.it`. The design system page is a living reference for the
tokens and components that the dashboard uses.

**Tone:** Academic data-journalism. Think Our World in Data, the FT's visual
storytelling pages, or Pudding.cool — authoritative, dense, warm. Not a SaaS
admin panel. Every element earns its place.

**The gravity metaphor** should subtly inform visual language: orbital motifs,
attraction/repulsion in colour semantics, the sense of mass and pull.

---

## Technical constraints

- One self-contained HTML file, inline CSS. No external dependencies.
- **System font stack only** — no custom web fonts. Push typographic hierarchy
  through weight, size, letter-spacing, and case.
- WCAG AA contrast on all text.
- Under 100 KB.
